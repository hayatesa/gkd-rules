# GKD 安全精简规则

一份静态 GKD 精简订阅，仅对规则中明确列出的普通应用生效。适合希望限制自动点击范围的用户。

- 11 个普通应用的 13 组规则，以及对 3 个应用明确白名单的 1 组全局规则。
- 无远程执行代码、无账户信息、无自动授权、无自动付款、无批量点击或坐标点击。
- 金融、支付、银行、贷款、证券、保险等敏感应用未加入规则白名单。
- **不是系统权限隔离**：GKD 的无障碍权限不因排除规则而失效；使用金融应用时，建议关闭 GKD 无障碍服务。
- 规则仅完成静态筛选，尚未在各版本应用中实测，不能保证零误触。建议首次启用时观察日志。

## 添加订阅

在 GKD 的订阅管理中添加：

```text
https://raw.githubusercontent.com/hayatesa/gkd-rules/main/gkd.json5
```

上述链接仅在本仓库以 **Public** 创建，且文件提交到 `main` 分支后才能使用。

## 发布及更新原则

所有更新应先人工审核，不自动同步第三方仓库。建议发布标签或使用固定提交 SHA 的 Raw 地址锁定版本。禁用其他订阅的全局自动点击规则，以免破坏白名单边界。
